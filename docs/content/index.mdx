`@inzero/barrel` is a CLI tool that generates barrel files for your project.

## Installation

```npm
npm install -g @inzero/barrel
```

## Features

- Generate barrel files for multiple extensions in one go.
- Configurable presets and defaults.

Command

```bash title='Terminal'
barrel src/**/index.*
```

## Commands

- [generate](/generate) (*Default*) - Generate barrel files.
